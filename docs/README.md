## 文档原则

- 公开配置与私有密钥分开说明；
- 所有发布步骤以差异预览为前置条件；
- 不把旧目录、旧接口或未验证命令写成当前事实；
- 技术专题遵循《技术笔记撰写规范 v2.0》。
