## 🎯 项目概览

YunYueBlogs 是一个高颜值、功能丰富的个人博客系统，采用现代化技术栈构建：

| 维度 | 技术选型 |
|------|----------|
| **前端框架** | Next.js 15 + React 19 |
| **样式系统** | Tailwind CSS 4 + Framer Motion |
| **后端服务** | Python FastAPI |
| **桌面客户端** | PyWebView |
| **部署平台** | GitHub Pages / Vercel |
| **AI 引擎** | Google Gemini / OpenAI |

### 核心特性

✨ **一键部署** - 双轨部署系统，支持静态站点和无服务器两种托管方式  
🎵 **音乐集成** - 深度整合网易云音乐，支持歌词同步显示  
🔄 **实时同步** - 本地与线上一键同步，操作队列暂存机制  
📱 **多端适配** - 响应式设计 + 创新圆形转盘导航  
🎨 **视觉盛宴** - 樱花飘落、萤火虫飞舞、星尘粒子等丰富特效  
🤖 **AI 助理** - 内置 AI 猫猫助理，支持自然语言对话  
🖼️ **图床集成** - 一键上传图片到云端图床  
💬 **评论系统** - 基于 GitHub Issues 的 Gitalk 评论

## 🛠️ 技术栈详情

### 前端技术栈

```
├── Next.js 15          # React 全栈框架
├── React 19            # UI 组件库
├── TypeScript          # 类型安全
├── Tailwind CSS 4      # 原子化 CSS
├── Framer Motion       # 动画引擎
├── Lucide React        # 图标库
└── Gitalk              # 评论组件
```

### 后端技术栈

```
├── Python 3.10+        # 运行环境
├── FastAPI             # Web 框架
├── Uvicorn             # ASGI 服务器
├── PyWebView           # 桌面窗口
├── HTTPX               # HTTP 客户端
└── Git                 # 版本控制
```

### 部署技术栈

```
├── GitHub Pages        # 静态托管 (A 线)
├── Vercel              # 无服务器托管 (B 线)
├── GitHub Actions      # CI/CD
└── CloudFlare          # CDN 加速
```
