# YunYueBlogs 2.0 项目总览

## 概述

YunYueBlogs 2.0 将公开阅读与本地管理分成两个边界清晰的应用：Astro 负责内容交付，星辉云端控制台负责无代码编辑、配置、同步和发布。

本次重构保留了 19 篇文章、1 篇杂谈和 1 条说说。迁移核对同时比较文件名与 SHA-256 正文哈希，差异为 0；旧源目录在确认前不删除。

## 产品结构

### 公开博客

| 页面 | 地址 | 说明 |
|------|------|------|
| 首页 | `/` | 人物主视觉、最新内容、限定弹幕与项目摘要 |
| 文章归档 | `/archive` | 全部文章与标签入口 |
| 杂谈 | `/chatter` | 非正式长内容 |
| 说说 | `/moments` | 短动态与图片 |
| 项目 | `/projects` | 结构化项目数据 |
| 相册 | `/photowall` | 相册与图片集合 |
| ACG 书架 | `/bangumi` | 只读公开收藏与状态筛选 |
| 友链 | `/friends` | 结构化友链数据 |
| 关于 | `/about` | 作者与站点说明 |

旧 `/timeline` 重定向到 `/archive`，旧 `/tree` 重定向到 `/projects`。文章、杂谈、说说、项目和相册地址保持不变。

### 星辉云端控制台

控制台导航固定为：概览、内容、媒体与资料、外观、集成、发布。桌面端使用工作台侧栏，窄屏使用抽屉导航；编辑、预览和发布操作均保留加载、错误和禁用状态。

## 视觉方向

- 纸白与墨黑承担阅读底色；
- 珊瑚红与青绿作为双强调色；
- 人物主视觉基于云月角色设定生成，保持深蓝长发、星纹发饰、羽毛和深蓝奶白服装；
- 毛玻璃只用于导航、播放器、抽屉与模态框；
- 首页弹幕在移动端、低性能设备和减少动画模式下关闭；
- 启动屏、点击粒子、天气挂件、随机背景、全局工具箱和 3D 灵境不再进入公开站。

## 功能边界

### 保留

- Markdown、数学公式、GFM、代码高亮、目录和旧换行兼容；
- 文章、杂谈、说说、项目、相册、友链、音乐、搜索和明暗主题；
- AI 助手、评论、图床与可选弹幕；
- 本地内容编辑、差异预览、中文 Git 提交和 GitHub 推送。

### 新增

- Astro Content Collections 与 JSON Schema 校验；
- Pagefind、RSS、Sitemap、规范链接和标签页；
- 文章第三方评论已移除，音乐评论保留；
- 只读 Bangumi 个人书架；
- 持久化操作队列、同步计划与发布任务状态。

### 不做

- 访客账户、站内关注或社区审核；
- Bangumi 登录、收藏写入或社区内容复制；
- 浏览器端 Git 凭据和图床密钥；
- 强制推送、自动重置或覆盖未知目录。
