# 博客 3.0 实施与验收记录

更新日期：2026-11-03。本文保留分阶段实现与验证记录；历史段落的“未部署”等状态只对应当时阶段。当前已进入生产交付，最终状态以末尾生产验收条目为准。

## 本轮视觉方向

公开站采用“私人编辑部”：非对称首页、角色场景、最近文字、作品、影像和私人电台。管理端采用“月下创作桌”：夜色侧栏、纸面内容和独立角色构图。保留本站品牌、三角色主题与既有路由；参考视频用于研究交互，不复制其代码、素材或整页排版。

参考视频长约 9 分 26 秒，本轮提取 98 帧，逐张查看覆盖全片的 9 张联系表，重点观察前台浏览、后台概览、编辑、影像、主题和文件管理。未完整核验音轨。研究文件留在被忽略的临时目录，不作为网站资源。

`ui-ux-pro-max` 用于玻璃层次、动效降级、可读性和操作反馈；管理端整页检索中的营销模板不适用，因此没有照搬。`grilling` 已确定唯一站长、零费用优先、保留品牌和静态发布等待等取舍。

## 公开博客改动

- 首页重新组织为作者场景、文字、作品、影像、音乐与角色书签；使用现有公开素材与数据。
- 顶部导航全部展开，依次为首页、文章、生活、项目、音乐、ACG 书架、相册、探索、友链、关于；手机使用五列两行。局部模糊、高光边缘与透明层次模拟液态玻璃，减少透明度时退回实色。
- 杂谈与说说合并为生活 `/journal`，按时间混排长随笔与日常片刻；旧索引跳转到生活，原长随笔详情继续可读。新增 `/explore`，由真实文章标签组织探索路径。
- 各页独立设计：文章装订目录、生活信纸、项目案例、相册展览、音乐电台、书架海报、友链通讯录与作者来信，保留全站角色色彩与字体。
- 归档筛选、URL 状态、阅读收藏、字号、专注模式、目录、图片预览和搜索保持原功能。
- 文章卡片与标题使用共享 View Transition；首页章节用 IntersectionObserver + Web Animations 渐进呈现。关闭脚本时正文仍可读。
- 桌面支持时使用原生 CSS Scroll-driven Animations，视差只移动装饰图片；文章增加原生阅读进度。手机/减少动态效果模式停用视差。
- 毛玻璃集中在导航和浮层。沿用本地字体、AVIF/WebP、尺寸占位和图片按需加载，不增加全站 WebGL、滚动接管或额外动画框架。
- 新文案涉及的 10 个字形增量并入已有字体主片，仅重建 9 个受影响分片，保留 47,449 字形完整覆盖。当前内容字体预算从约 1,027 KiB 降至 430 KiB，仍使用原有授权字体与 1 MiB 构建门槛。
- 保留持久音乐实例。首屏不查询音源，进入音乐区域才加载信息，点击播放才请求音频；跨页继续播放。

## 新管理端改动

源码位于 `apps/console`，详见其 README。

- 用户指定的管理账号通过私有初始化批次准备，密码未写入源码；首次登录服务端强制改密。
- 额外使用 24 小时一次性激活票据，避免已知初始密码导致抢先认领。
- 文稿、修订、会话、限流与任务持久化在 D1；修订使用版本比较防止覆盖其他设备内容。
- 支持自动保存、离线草稿恢复、Markdown 安全预览、卡片/紧凑视图、筛选、快捷搜索。
- 站点、作品、相册与友链支持可视化表单；歌单等未展示字段保留，仍可切换高级源码。
- 原生场景过渡支持快速取消与减少动态效果；角色、便笺、星体使用分层轻视差，手机停用。
- 统计图只展示实际文稿构成。额度数字是保护目标，未接入实际平台统计，不展示虚构访问趋势。

控制台完整构建与首次激活至退出的浏览器流程通过，连续换角色不再产生未处理的过渡取消异常。界面截图检查覆盖前台首页、归档、项目、相册、关于与文章，以及管理概览、文稿、预览、编辑器和配置表单。

所有当前页面与截图证据均来自本地浏览器。没有真实手机弱网验收、生产迁移、生产密码服务或新管理端生产域名证据。

## 11 月 3 日最新增量：音乐分流、配置工作台与交互反馈

本节更新前文的阶段状态；先前的生产 Redis 音频兜底方案已被替换，正式构建配置缺失时返回可操作的失败提示，不会回落到 Vercel 传输音频。

- 后台增加独立音乐、图床与书架入口。支持歌单编辑排序/试听、歌词原文/翻译/罗马音及偏移、默认音质、两平台二维码及状态维护、脚本导入测试后启用、图床公开上传与编辑器选图，以及书架分类/标题/介绍。
- 私有连接在 D1 中 AES-GCM 加密，写入比较 revision；返回摘要不回显 Cookie、Token、脚本。二维码只允许单次认领，迟到状态不能覆盖后续账号版本。公开 JSON 保存时拒绝私密字段、重复歌曲和越界歌词。
- 原站 HTTPS 经过严格 TLS 与 Range 探测，不可用时由 Cloudflare 原字节中转。独立部署配置位于 `apps/console/music-worker`；传输入口不持有账号解密与发布密钥。详情、费用与音质依据见《洛雪音乐音源架构评估》。
- 播放器增加最高兼容音质，切换保留歌曲和进度，取消旧请求批次、隔离缓存；已有 selectedSongId/selectionGeneration/ended 校验继续保留。无损解码失败回退，访客仍可选择节省流量的 320 kbps。
- 参考 [QWidgetSekai 固定版本](https://github.com/Aegisir/QWidgetSekai/tree/9da6895f6a6c34ca0f0aa48587771147d80a07e5) 的导航重定向、短反馈及分层视差思想，使用独立 Web 实现；没有复制其 GPL-3.0 的 Python/Qt 源码，也没有新增 Qt 运行时。
- 两端导航滑块从当前视觉位置重定向，短开关反馈；音乐背景取消堆叠退出与长时间放大，页面/筛选内容先即时更新。首页原生滚动时间轴优先，旧浏览器用可见时按滚动事件更新的 requestAnimationFrame；减少动态效果停用视差。

本轮真实验证：公开站 123 项单测、Node 5 项测试、控制台 22 项单测和扩展后的完整激活至退出浏览器流程；该流程包含音乐/歌词/扫码/音源暂存测试启用、书架、图床 Token 与模拟上传。公开站 20 项音乐与动效浏览器用例通过，修正主视觉图层后又通过 7 项导航/动效回归。真实音源取源与 Range 另外测试，不把模拟扫码、模拟上传和合成音频当作平台真实登录或整曲播放证据。

已完成两端构建和独立传输 Worker 构建。仍未提交、推送、部署、启用付费服务、确认真实扫码或做生产发布流水线切换。站长人工预览的密码和文稿保持原有持久库，测试改密仅发生在临时数据库。


人工预览最终检查另外发现 Miniflare 5 会忽略旧的 `d1Persist/r2Persist` 参数，现已改为统一 `resourcePersistencePath`。已从本任务的旧临时库恢复原改密状态和 26 份内容/配置，迁入持久库后实际重启回读，密码哈希、密码版本和既有文稿逐项一致。新增测试覆盖 D1 与 R2 的跨实例恢复；自动验收仍使用独立临时库。恢复文件只放在忽略目录，已有人工库不允许直接覆盖恢复。


恢复持久化后，真实《玄翎谣》的 FLAC 在 Chrome 成功解码，显示完整约 278 秒时长，播放进度推进至约 32.8 秒后主动暂停；并非完整听完。当前本地入口为 `http://127.0.0.1:4321/` 与 `http://127.0.0.1:5173/?view=music`。两端仍保持运行，控制台使用恢复的既有密码，真实平台扫码及生产配置未执行。

## 11 月 3 日音乐检索工作台调整

本节替代前文仍提供音乐账号、手动排轴入口的界面描述。音乐管理只保留「检索与歌单」「自定义音源」，移除扫码登录和音乐账号状态路由。旧加密连接与历史歌词配置未进行永久删除，也未重置站长账号、密码或已有文稿。既有自动 KRC/逐行歌词继续按选中歌曲加载，无需站长主动排轴。

- 左侧主区域改为模糊歌曲检索、试听、添加歌单、排序与编辑，右侧设置栏承载「播放音质与访客流量」。小屏通过设置按钮打开播放设置；博客访客只能看到实际音质，不能自行调整。
- 当前音源声明的网易云、酷狗、QQ、酷我、咪咕五渠道均接入关键词目录查询。渠道可在搜索前选择，也可检索后直接切换并保留关键词。显示歌手、专辑、时长、封面和质量标签，支持分页、防重复收录；试听返回的是实际探测到的音质。
- 不随每次输入请求：点击按钮或回车才检索。每页 15 条、最多 50 页；前端 60 键、Node 128 键及边缘短期缓存均为 5 分钟，同请求合并、旧搜索取消并校验请求代次，换源按 SHA 隔离缓存。Node 检索并发最多 4；自定义解析并发最多 2，忙时不自动重试；管理搜索与试听另有分钟限流。
- 新增三渠道的公开标识及质量 Hash 随站点配置保存、发布并传给取源器；访客请求不能替换已发布曲目的内部标识。元数据筛选、固定媒体域名、TLS/Range/真实格式与体积检查、票据与预算继续有效。目录检索借鉴 LX Music Desktop 的对应接口映射，保留 Apache-2.0 许可与出处，未引入 Electron。
- QQ 样本的脚本计算较重，隔离执行单次总 CPU 预算最多 8 秒，单段最多 6 秒；其他渠道保留较低预算，48 MB 堆与约 21 秒解析截止时间继续有效。实测 QQ 样本返回的 Range 内容不识别为 MP3/FLAC，当前明确返回试听失败，不等于五渠道每首歌都能播放，也未增加解密或音频转码服务。
