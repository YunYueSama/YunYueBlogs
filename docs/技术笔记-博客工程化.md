# 技术笔记：博客工程化

## 概述

一种通过管理端、发布端和云端部署串联内容生产的 **博客工程化技术**。

其核心特征是：

- 用管理端承载写作、配置和资源管理；
- 用发布端承载公开访问页面；
- 用本机后端执行文件和 Git 操作；
- 用 Vercel 保留需要服务端代理的接口能力。

## 分类

所属分类：组件架构

## 核心技术内容

### 技术原理

YunYueBlogs 不是单纯的静态博客，而是把内容生产、配置管理、资源上传和部署发布拆成两层：

- `my-blog-manager`：本地控制台，负责写文章、改配置、上传图床、管理评论参数、同步部署；
- `YunYueBlog`：公开博客项目，负责线上访问、评论、音乐、弹幕和视觉展示；
- `cms_core`：FastAPI 本机后端，负责执行浏览器不能直接完成的文件写入、目录同步、Git 和 HTTP 上传；
- `app/api/*`：Next.js 线上 API，负责 GitHub OAuth、音乐聚合、AI 助手等服务端代理。

### 核心实现

```text
YunYueBlogs/
├─ my-blog-manager/       # 本地控制台与管理端数据源
│  ├─ app/settings/       # 控制台配置入口
│  ├─ components/         # 编辑器、播放器、评论、弹幕、视觉组件
│  └─ cms_core/api/       # 本机 FastAPI 文件/Git/图床接口
├─ YunYueBlog/            # 公开博客发布目录
│  ├─ app/                # Next.js 页面与线上 API Route
│  ├─ components/         # 前台展示组件
│  └─ siteConfig.ts       # 发布端站点配置
└─ docs/                  # 项目文档与技术笔记
```

### 参数说明

| 参数 | 作用 | 推荐值 | 说明 |
|------|------|--------|------|
| `blogPath` | 发布端物理路径 | `YunYueBlog` 目录 | 控制台同步和部署的目标目录 |
| `siteConfig.ts` | 站点全局配置 | 管理端维护 | 保存头像、背景、音乐、评论等配置 |
| `backend_config.json` | 本机后端端口 | 自动生成 | 前端读取后调用 FastAPI |
| `sourceRepoUrl` | Vercel 源码仓库 | SSH 地址 | 用于触发线上构建 |
| `GEMINI_API_KEY` | AI 助手密钥 | 环境变量 | 不应写入仓库 |

### 设计要点

- 管理端和发布端分离，避免线上站点直接拥有本地文件写权限；
- 控制台先暂存操作，再批量落盘，降低误操作影响；
- 发布端保留 Next API Route，满足 GitHub OAuth 和音乐接口代理；
- 敏感配置在同步阶段过滤，避免图床 Token 被写入发布目录。

## 适用场景

- 个人博客需要可视化后台管理时；
- 静态内容和动态代理接口需要同时存在时；
- 内容发布需要经过本地审核和同步流程时；
- 希望非代码方式维护站点配置时。

## 注意事项

- GitHub 评论、音乐和 AI 助手依赖线上 API Route，纯静态托管无法完整运行；
- 图床 Token、AI Key、OAuth Secret 不应写入公开仓库；
- 同步发布前应先确认 `blogPath` 指向真实博客目录。
