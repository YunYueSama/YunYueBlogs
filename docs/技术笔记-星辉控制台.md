# 技术笔记：星辉控制台

## 概述

一种通过桌面窗口同时承载 Next.js 前端和 FastAPI 后端的 **星辉控制台技术**。

其核心特征是：

- 用 PyWebView 包装本地 Web 控制台；
- 用随机端口启动前端和后端服务；
- 用 JSON 文件把后端端口暴露给前端；
- 用窗口 API 接管最小化、最大化和关闭。

## 分类

所属分类：组件架构

## 核心技术内容

### 技术原理

控制台本质是一个本地桌面壳。`launcher.py` 负责启动 Next.js 前端与 FastAPI 后端，再用 PyWebView 打开控制台页面。后端端口不是写死的，而是在运行时选择可用端口，并写入 `public/backend_config.json`，前端再读取该文件调用 `127.0.0.1` API。

### 核心实现

```py
frontend_port = get_free_port()
backend_port = get_free_port()

write_port_config(backend_port)
threading.Thread(target=run_api, args=(backend_port,), daemon=True).start()

window = webview.create_window(
    title="星辉云端·控制台",
    url=f"http://127.0.0.1:{frontend_port}",
    width=1440,
    height=900,
    min_size=(1024, 768),
    frameless=True,
    js_api=WindowAPI(),
)
```

```ts
const configRes = await fetch(`/backend_config.json?t=${Date.now()}`);
const config = await configRes.json();
await fetch(`http://127.0.0.1:${config.api_port}/api/status`);
```

### 参数说明

| 参数 | 作用 | 推荐值 | 说明 |
|------|------|--------|------|
| `frontend_port` | 控制台页面端口 | 自动分配 | 避免端口冲突 |
| `backend_port` | FastAPI 端口 | 自动分配 | 写入 `backend_config.json` |
| `HOSTNAME` | Next 监听地址 | `127.0.0.1` | 生产模式下限制本机访问 |
| `min_size` | 窗口最小尺寸 | `1024 x 768` | 防止控制台布局挤压 |
| `window_config.json` | 记忆窗口尺寸 | 本地文件 | 下次启动恢复窗口大小 |

### 设计要点

- 前端负责交互，后端负责文件系统、Git、外部上传等高权限操作；
- 端口动态生成，降低与其他开发服务冲突的概率；
- `backend_config.json` 加时间戳读取，避免浏览器缓存旧端口；
- 桌面窗口关闭时释放前后端进程，避免残留服务占用端口。

## 适用场景

- 本地 CMS 需要桌面化交付时；
- Web UI 需要调用本机文件系统能力时；
- 希望普通用户免命令行启动复杂工具时；
- 前后端服务需要一键启动和统一退出时。
