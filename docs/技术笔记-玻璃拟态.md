# 技术笔记：玻璃拟态

## 概述

一种通过半透明背景、背景模糊和多层环境光建立空间层次的 **玻璃拟态技术**。

其核心特征是：

- 用 `backdrop-blur` 模糊背后内容；
- 用半透明背景保留环境色；
- 用边框和阴影强化面板边界；
- 用全局背景层统一页面氛围。

## 分类

所属分类：布局系统

## 核心技术内容

### 技术原理

项目没有把毛玻璃当成单个卡片样式，而是在 `RootLayout` 中先建立背景图、渐变遮罩、模糊覆盖、环境光和动态特效，再让页面组件使用半透明面板叠在上方。这样每个面板都能透出同一套背景环境，视觉上更统一。

### 核心实现

```tsx
<div className="fixed inset-0 z-[-1] pointer-events-none overflow-hidden">
  {!siteConfig.useGradient && <BackgroundSlider />}
  <div className="absolute inset-0 bg-white/30 dark:bg-slate-900/40 backdrop-blur-md" />
  <div
    className="absolute inset-0 opacity-60 dark:opacity-20 mix-blend-color"
    style={{
      background: `linear-gradient(-45deg, ${siteConfig.themeColors.join(", ")})`,
      backgroundSize: "400% 400%",
      animation: "gradientMove 15s ease infinite",
    }}
  />
</div>
```

```css
[class*="backdrop-blur-"] {
  will-change: backdrop-filter;
  -webkit-backdrop-filter: blur(12px);
}

@-moz-document url-prefix() {
  [class*="backdrop-blur-md"] {
    backdrop-filter: blur(8px) !important;
  }
}
```

### 参数说明

| 参数 | 作用 | 推荐值 | 说明 |
|------|------|--------|------|
| `bg-white/40` | 面板透明度 | `30%` 到 `60%` | 保留背景色但保证文本可读 |
| `backdrop-blur-md` | 背景模糊 | `8px` 到 `16px` | 过高会增加渲染成本 |
| `border-white/40` | 面板边界 | `20%` 到 `50%` | 分离背景与内容 |
| `shadow-xl` | 面板投影 | 中等阴影 | 提升浮层层次 |
| `themeColors` | 环境渐变色 | 3 到 5 个色值 | 用于统一页面氛围 |

### 设计要点

- 背景层使用负 z-index，内容层保持 `relative z-10`；
- 毛玻璃面板需要边框，否则在浅色背景上边界会消失；
- 暗色模式要降低背景透明度，防止文字对比度不足；
- 对 `backdrop-filter` 添加兼容和性能提示，减少滚动卡顿。

## 适用场景

- 个人博客首页的卡片矩阵；
- 设置页和控制台的配置面板；
- 评论区和弹窗浮层；
- 音乐播放器的背景氛围层。
