# 技术笔记：背景弹幕

## 概述

一种通过配置列表随机生成横向漂浮文字的 **背景弹幕技术**。

其核心特征是：

- 用配置数组管理弹幕内容；
- 用随机高度、时长和延迟生成弹幕；
- 用固定背景层限制弹幕范围；
- 用 CSS keyframes 实现循环横移。

## 分类

所属分类：动画与缓动

## 核心技术内容

### 技术原理

弹幕不是实时消息系统，而是一个配置驱动的环境装饰层。设置页维护 `danmakuList`，保存后写入 `siteConfig.ts`。前台组件读取该列表，随机生成固定数量弹幕，并在页面顶部 30vh 范围内循环从右向左移动。

### 核心实现

```ts
const list = siteConfig.danmakuList || [];
const generatedDanmakus = [];

for (let i = 0; i < 15; i++) {
  generatedDanmakus.push({
    id: i,
    text: list[Math.floor(Math.random() * list.length)],
    top: Math.random() * 80 + 10,
    duration: Math.random() * 20 + 25,
    delay: Math.random() * 20,
  });
}
```

```css
@keyframes float-left {
  0% {
    right: -100%;
    transform: translateX(100%);
  }
  100% {
    right: 100%;
    transform: translateX(-100%);
  }
}
```

### 参数说明

| 参数 | 作用 | 推荐值 | 说明 |
|------|------|--------|------|
| `danmakuList` | 文案池 | 10 条以上 | 内容从中随机抽取 |
| `count` | 同屏生成数量 | `15` | 数量过多会干扰阅读 |
| `top` | 垂直位置 | `10%` 到 `90%` | 避免文字被容器切掉 |
| `duration` | 横移时长 | `25s` 到 `45s` | 保持慢速环境感 |
| `delay` | 动画延迟 | `0s` 到 `20s` | 错开弹幕起点 |
| `height` | 弹幕区域高度 | `30vh` | 避免覆盖正文 |

### 设计要点

- 弹幕层设置 `pointer-events-none`，不阻挡页面点击；
- 文本透明度较低，保证它是背景氛围而不是正文内容；
- 容器固定在顶部区域，避免整屏弹幕影响阅读；
- 设置页做空值和重复值校验，减少无效配置。

## 适用场景

- 个人博客首页的氛围装饰；
- 活动页或专题页的轻量背景动效；
- 控制台设置项需要即时管理文案池时；
- 不需要实时互动的弹幕展示。
