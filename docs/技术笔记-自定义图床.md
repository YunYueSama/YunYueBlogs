# 技术笔记：自定义图床

## 概述

一种通过本地后端代理上传并统一转换图片直链的 **自定义图床技术**。

其核心特征是：

- 在控制台配置图床地址和 Token；
- 用探针请求验证 Token 可用性；
- 用 FormData 通过本机后端上传文件；
- 用直链转换函数修正图床返回地址。

## 分类

所属分类：组件架构

## 核心技术内容

### 技术原理

图床 Token 不直接交给线上发布端使用，而是在本地管理端配置。控制台的图库设置页调用 FastAPI 探针接口验证 Token；编辑器图片浮窗支持拖拽上传和外链插入；后端上传成功后返回图片直链，前端再将链接插入正文或背景配置。

### 核心实现

```ts
const uploadData = new FormData();
uploadData.append("file", file);
uploadData.append("url", picUrl);
uploadData.append("token", picToken);

await fetch(`http://127.0.0.1:${apiPort}/api/picbed/upload`, {
  method: "POST",
  body: uploadData,
});
```

```py
upload_endpoint = f"{url}/upload"
headers = {"Authorization": f"Bearer {token}"}
files = {"file": (file.filename, content, file.content_type)}

response = await client.post(upload_endpoint, headers=headers, files=files)
```

```ts
export function toDirectUrl(url: string, picBedBase?: string): string {
  const base = picBedBase?.replace(/\/$/, "");
  if (base && url.startsWith(base + "/") && !url.includes("/file/")) {
    return url.replace(base + "/", base + "/file/");
  }
  return url || "";
}
```

### 参数说明

| 参数 | 作用 | 推荐值 | 说明 |
|------|------|--------|------|
| `picBedName` | 图床名称 | 自定义 | 只用于后台识别 |
| `picBedUrl` | 图床基础地址 | HTTPS 地址 | 上传接口会拼接 `/upload` |
| `picBedToken` | 图床鉴权 | 后台生成 Token | 不应写入公开仓库 |
| `file` | 上传文件 | 图片类型 | 前端限制 `accept="image/*"` |
| `timeout` | 上传超时 | `60s` | 大图上传需要更长时间 |

### 设计要点

- 探针先访问服务地址，再用空上传请求区分 Token 无效和文件缺失；
- 上传接口只返回必要的图片 URL，不把 Token 暴露给发布端；
- 外链插入也经过 `toDirectUrl`，避免图床页面链接无法渲染；
- `sync.py` 同步 `siteConfig.ts` 时过滤 `picBedToken`。

## 适用场景

- Markdown 编辑器需要快速插入远程图片时；
- 背景图、头像、封面图需要统一托管时；
- 图床服务返回页面链接而不是直链时；
- 本地控制台需要代理上传避免跨域和鉴权暴露时。

## 注意事项

- 当前管理端配置文件中存在 `picBedToken` 字段，公开提交前应确认已过滤或轮换；
- 不同图床返回结构不同，接入新服务时需要调整响应解析；
- 图片过大或图床网络不稳定时，应保留超时和错误提示。
