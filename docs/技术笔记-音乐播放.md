# 技术笔记：音乐播放

## 概述

一种通过歌曲 ID 聚合元数据、歌词和音频地址的 **音乐播放技术**。

其核心特征是：

- 用控制台维护网易云歌曲 ID；
- 用后端接口校验歌曲元数据；
- 用前台 API 聚合详情和歌词；
- 用全局 Provider 管理播放状态。

## 分类

所属分类：组件架构

## 核心技术内容

### 技术原理

音乐系统分成两段：控制台设置页调用 FastAPI 查询单首歌曲，确认 ID 有效后写入 `cloudMusicIds`；前台 `MusicProvider` 读取这些 ID，调用 Next API `/api/music` 并行获取歌曲详情和歌词，然后用同一个 Provider 向首页卡片、浮动播放器和音乐页暴露播放状态。

### 核心实现

```ts
const res = await fetch(`/api/music?ids=${siteConfig.cloudMusicIds.join(",")}`);
const rawResults = await res.json();

const playlist = rawResults
  .filter((song) => song && song.url && !song.error)
  .map((song) => ({
    id: song.id,
    title: song.name,
    artist: song.artist,
    cover: song.cover,
    src: song.url,
    lyrics: song.lrc ? parseLrc(song.lrc) : [],
  }));
```

```ts
const [detailRes, lrcRes] = await Promise.all([
  fetch(`https://music.163.com/api/song/detail/?id=${songId}&ids=[${songId}]`, {
    headers: NET_EASE_HEADERS,
    signal: AbortSignal.timeout(6000),
  }),
  fetch(`https://music.163.com/api/song/lyric?id=${songId}&lv=-1&kv=-1&tv=-1`, {
    headers: NET_EASE_HEADERS,
    signal: AbortSignal.timeout(6000),
  }).catch(() => null),
]);
```

### 参数说明

| 参数 | 作用 | 推荐值 | 说明 |
|------|------|--------|------|
| `cloudMusicIds` | 歌曲 ID 列表 | 字符串数组 | 控制台维护 |
| `NET_EASE_HEADERS` | 请求伪装头 | 浏览器 UA + Referer | 降低接口拒绝概率 |
| `AbortSignal.timeout` | 单请求超时 | `6000ms` | 防止页面等待过久 |
| `playMode` | 播放模式 | `loop` | 支持循环、单曲、随机 |
| `volume` | 播放音量 | `0` 到 `1` | Provider 同步到 audio |
| `lyrics` | 歌词时间轴 | LRC 解析结果 | 用于当前歌词显示 |

### 设计要点

- 歌曲 ID 先在控制台真实查询，减少发布后无效歌曲；
- 前台 API 并行请求详情和歌词，歌词失败不影响播放；
- LRC 解析会过滤控制字符并支持多个时间戳；
- 播放状态集中在 `MusicProvider`，多个 UI 组件共享同一音频源。

## 适用场景

- 博客首页需要轻量 BGM 挂件时；
- 音乐页需要歌单、歌词和播放控制时；
- 多个页面组件需要共享同一个播放状态时；
- 歌曲列表由后台配置而不是写死在组件中时。

## 注意事项

- 网易云外链可能因版权、地区或网络策略失效；
- 浏览器自动播放策略可能阻止未交互播放；
- `/api/music` 需要可运行的 Next API Route，纯静态托管无法使用。
