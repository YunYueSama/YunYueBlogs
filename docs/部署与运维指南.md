# 🌐 部署与运维指南

本文档详细介绍 YunYueBlogs 的部署流程、环境配置和常见问题解答。

---

## 1. 环境要求

### 1.1 必需环境

| 环境 | 版本要求 | 用途 |
|------|----------|------|
| **Node.js** | v18.x 或以上 | Next.js 运行环境 |
| **Python** | 3.10 或以上 | 后端服务运行环境 |
| **Git** | 最新版 | 版本控制与部署 |
| **npm** | 随 Node.js 安装 | 包管理器 |

### 1.2 可选环境

| 环境 | 用途 |
|------|------|
| **GitHub 账号** | 托管代码、评论系统、部署 |
| **Vercel 账号** | 无服务器部署 (B 线) |
| **图床服务** | 图片托管 (推荐 CloudFlare-ImgBed) |
| **Google AI API** | AI 猫猫助理 (Gemini) |

## 2. 快速开始

### 2.1 克隆项目

```bash
# 克隆管理端仓库
git clone git@github.com:YunYueSama/YunYueBlogs.git

# 进入项目目录
cd YunYueBlogs

# 克隆前端仓库（子目录）
git clone git@github.com:YunYueSama/YunYueBlog.git
```

### 2.2 启动管理后台

```bash
# 进入管理端目录
cd my-blog-manager

# Windows 用户：双击 Start.bat
# 或手动运行：
python run_me.py
```

`Start.bat` 会自动：
1. 检测 Python 版本（要求 3.10+）
2. 安装 Python 依赖（fastapi, uvicorn, pywebview 等）
3. 安装 Node.js 依赖（npm install）
4. 启动桌面客户端

### 2.3 配置前端路径

首次启动后，在控制台"设置"页面配置前端物理路径：

```
前端物理路径：D:\Projects\YunYueBlogs\YunYueBlog
```

点击 **[测试路径]** 验证连通性，然后点击 **[保存配置]**。

## 3. 双轨部署系统

### 3.1 静态页面部署

适用于静态博客部署，免费且稳定。

#### 步骤 1：创建代码仓库

```bash
# 在 GitHub 创建新仓库（建议设为私有）
# 仓库名：my-blog 或自定义
```

#### 步骤 2：配置推送密钥

```bash
# 生成 SSH 密钥
ssh-keygen -t ed25519 -C "your_email@example.com" -f ~/.ssh/id_ed25519

# 复制公钥
cat ~/.ssh/id_ed25519.pub
```

将公钥添加到 GitHub 仓库的 **Settings → Deploy keys**，勾选 **Allow write access**。

#### 步骤 3：配置仓库地址

在控制台"设置"页面：
- **仓库地址**：`git@github.com:your-username/my-blog.git`
- **部署分支**：`main`

#### 步骤 4：执行部署

点击 **[仅同步源码]** 按钮，程序将：
1. 同步文件到前端目录
2. 执行 `git add . && git commit && git push`
3. 触发 GitHub Pages 构建

#### 步骤 5：配置自定义域名（可选）

在 GitHub 仓库 **Settings → Pages → Custom domain** 填入你的域名，然后在 DNS 服务商添加 CNAME 记录指向 `your-username.github.io`。

---

### 3.2 源码触发部署

适用于需要 Serverless Functions 的场景（如 AI 聊天、图床上传）。

#### 步骤 1：复刻前端仓库

```bash
# 在 GitHub Fork YunYueBlog 仓库
# 或创建新仓库并推送代码
```

#### 步骤 2：连接云端构建平台

1. 访问 [vercel.com](https://vercel.com)
2. 使用 GitHub 账号登录
3. 点击 **Add New... → Project**
4. 选择 Fork 的仓库
5. Framework Preset 选择 **Next.js**
6. 点击 **Deploy**

#### 步骤 3：配置环境变量

在 Vercel 项目 **Settings → Environment Variables** 添加：

```env
# AI 配置（可选）
GEMINI_API_KEY=your_gemini_api_key

# GitHub OAuth（评论系统）
NEXT_PUBLIC_GITALK_CLIENT_ID=your_client_id
NEXT_PUBLIC_GITALK_CLIENT_SECRET=your_client_secret
```

#### 步骤 4：配置自定义域名

在 Vercel 项目 **Settings → Domains** 添加你的域名，然后在 DNS 服务商添加：
- A 记录：`76.76.21.21`
- CNAME 记录：`cname.vercel-dns.com`

---

### 3.3 双轨部署配置

在控制台"设置"页面配置双轨部署：

| 配置项 | A 线 | B 线 |
|--------|------|------|
| **仓库地址** | 静态部署仓库 | Vercel 关联仓库 |
| **部署分支** | main | main |
| **SSH 密钥** | ~/.ssh/id_ed25519 | ~/.ssh/id_ed25519_source |

配置完成后，点击 **[保存双轨配置]**。

## 4. 网易云音乐配置

### 4.1 获取歌曲编号

1. 打开网易云音乐网页版
2. 搜索并进入歌曲详情页
3. 浏览器地址栏 URL 中的数字即为歌曲 ID

例如：`https://music.163.com/song?id=123456789`，ID 为 `123456789`。

### 4.2 添加歌曲

在控制台"音乐设置"页面：
1. 输入歌曲 ID
2. 点击 **[查询]** 预览歌曲信息
3. 点击 **[添加到播放列表]**
4. 点击 **[暂存到操作队列]**
5. 最后点击 **[同步 Blog]**

## 6. 评论系统配置

### 6.1 创建代码托管授权应用

1. 登录 GitHub，进入 **Settings → Developer settings → OAuth Apps**
2. 点击 **New OAuth App**
3. 填写信息：
   - **Application name**：`My-Blog-Comments`
   - **Homepage URL**：`https://your-domain.com`
   - **Authorization callback URL**：`https://your-domain.com`
4. 点击 **Register application**
5. 复制 **Client ID**
6. 点击 **Generate a new client secret**，复制密钥

### 6.2 配置评论

在控制台"评论设置"页面：
- **Client ID**：填入上一步获取的 Client ID
- **Client Secret**：填入上一步获取的密钥
- **仓库名**：用于存储评论的 GitHub 仓库（需为 Public）
- **用户名**：你的 GitHub 用户名

### 6.3 创建评论仓库

在 GitHub 创建一个 **Public** 仓库用于存储评论，例如 `blog-comments`。

## 8. 常见问题解答

### 问题一：启动脚本闪退怎么办？

**A：** 使用 CMD 手动运行：

```cmd
cd my-blog-manager
python run_me.py
```

如果提示 Python 版本错误，请安装 Python 3.10 或以上版本。

### 问题二：依赖安装失败怎么办？

**A：** 尝试以下解决方案：

```bash
# 清除缓存
npm cache clean --force

# 删除 node_modules 重新安装
rm -rf node_modules
npm install

# 使用国内镜像
npm install --registry=https://registry.npmmirror.com
```

### 问题三：代码推送失败怎么办？

**A：** 检查 SSH 密钥配置：

```bash
# 测试 SSH 连接
ssh -T git@github.com

# 如果失败，检查密钥是否正确添加
ssh-add ~/.ssh/id_ed25519
```

### 问题四：云端部署失败怎么办？

**A：** 检查以下几点：
1. 确认 Framework Preset 选择的是 **Next.js**
2. 确认环境变量配置正确
3. 查看 Vercel 构建日志定位错误

### 问题五：智能猫猫不回复怎么办？

**A：** 检查以下几点：
1. 确认 API Key 配置正确
2. 确认网络可以访问 Google/OpenAI API
3. 检查浏览器控制台是否有错误信息

### 问题六：评论系统不显示怎么办？

**A：** 检查以下几点：
1. 确认 GitHub OAuth App 配置正确
2. 确认评论仓库为 Public
3. 确认 Client ID 和 Client Secret 正确

### 问题七：图片上传失败怎么办？

**A：** 检查以下几点：
1. 确认图床地址和 Token 正确
2. 确认网络可以访问图床服务
3. 检查图片大小是否超过限制

## 9. 更新与维护

### 9.1 一键更新

```bash
# Windows 用户：双击 update.bat
# 或手动运行：
python update.py
```

更新脚本会：
1. 拉取最新代码
2. 精准覆盖核心文件
3. 安装依赖
4. 修复配置文件

### 9.2 手动更新

```bash
# 进入项目目录
cd YunYueBlogs

# 拉取最新代码
git fetch origin main

# 覆盖指定文件
git checkout origin/main -- YunYueBlog/components/CyberCat.tsx
git checkout origin/main -- my-blog-manager/cms_core/api/config.py
# ... 更多文件

# 安装依赖
cd YunYueBlog && npm install
cd ../my-blog-manager && npm install
```

### 9.3 备份数据

重要数据存储位置：

```
YunYueBlogs/
├── my-blog-manager/
│   ├── posts/           # 文章数据
│   ├── chatters/        # 杂谈数据
│   ├── moments/         # 动态数据
│   └── siteConfig.ts    # 站点配置
└── YunYueBlog/
    └── siteConfig.ts    # 前端配置
```

建议定期备份这些文件。

## 10. 性能优化建议

### 10.1 图片优化

- 使用 WebP 格式
- 压缩图片大小
- 使用 CDN 加速

### 10.2 缓存配置

在 Vercel 或 GitHub Pages 配置缓存头：

```
Cache-Control: public, max-age=31536000, immutable
```

### 10.3 代码分割

Next.js 自动进行代码分割，无需手动配置。

## 11. 安全建议

### 11.1 敏感信息保护

- 不要将 API Key 提交到 Git
- 使用环境变量存储敏感信息
- 定期轮换 API Key

### 11.2 仓库安全

- 建议将部署仓库设为私有
- 使用 Deploy Keys 而非 Personal Access Token
- 定期检查仓库权限

### 11.3 网站安全

- 启用 HTTPS
- 配置 CSP 头
- 定期更新依赖
