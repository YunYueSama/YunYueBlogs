# 项目架构详解

## 总体架构

```text
本地管理端
Next.js 16 UI -> FastAPI -> my-blog-manager/workspace
                              |
                              v
                       sync plan / apply
                              |
                              v
公开博客仓库 -> GitHub main -> Vercel -> Astro 静态页面与服务端函数
```

系统保持两个发布边界。管理端仓库只保存程序代码；内容与私有配置留在被忽略的 `workspace/`。公开博客仓库保存可发布内容和公开 JSON，不包含 Git 凭据、图床 Token 或 AI Key。

## 公开博客

### 技术栈

| 技术 | 职责 |
|------|------|
| Astro 7 | 静态路由、内容渲染与服务端函数 |
| React 19 Islands | 搜索、音乐、AI 和 Bangumi 交互 |
| Tailwind CSS 4 | 构建期样式能力，主体设计由项目 CSS 变量约束 |
| Content Collections | Markdown 加载与 Zod 校验 |
| Pagefind | 构建后的静态全文检索 |
| Vercel Adapter | Bangumi、音乐和 AI 服务端接口 |

### 内容契约

| 集合 | 目录 | 必填字段 | 公开地址 |
|------|------|----------|----------|
| `posts` | `posts/*.md` | `title`、`date` | `/posts/[slug]` |
| `chatters` | `chatters/*.md` | `title`、`date` | `/chatter/[slug]` |
| `moments` | `moments/*.md` | `date` | `/moments` |
| `pages` | `content/*.md` | `title` | 固定页面 |

文件名去掉 `.md` 后直接作为 slug。日期接受 ISO 日期和旧式日期文本，并在集合层统一转换为 `Date`。项目、相册、友链与公开站点配置位于 `src/data/*.json`。

### 服务端接口

| 接口 | 边界 | 降级策略 |
|------|------|----------|
| `/api/bangumi/collections` | 只读公开收藏，8 秒超时，最多 200 条 | 未配置、空用户、限流和超时均返回明确错误码 |
| `/api/music` | 最多 12 个网易云 ID 或酷狗 hash，服务端超时与缓存 | 单曲失败不阻断其他歌曲，KRC 失败回退 YRC/LRC |
| `/api/chat` | 单条 1 至 1000 字，每 IP 每分钟 8 次，并发 12 | 缺少 Key 返回 503，模型超时返回 504 |

文章第三方评论已移除；音乐评论通过服务端获取并在音乐页展示。

## 管理端

### 本地工作区

```text
workspace/
├── content/
│   ├── posts/
│   ├── chatters/
│   ├── moments/
│   └── about.md
├── data/
│   ├── site.json
│   ├── projects.json
│   ├── albums.json
│   └── friends.json
├── drafts/
├── config/
│   ├── deploy.json
│   ├── integrations.json
│   └── secrets.json
├── plans/
├── jobs/
└── operations.json
```

首次启动会执行幂等迁移：只复制缺失文件，不覆盖工作区内容，也不删除旧目录。公开配置与私有密钥分开保存；设置接口仅返回 `Configured` 布尔值，不回显密钥。

### 同步状态机

1. `POST /api/sync/plan` 校验真实路径、Git 根目录、项目标识、源文件哈希和目标仓库状态；
2. `POST /api/sync/apply` 按 32 位 `planId` 重新校验状态，在进程锁内暂存、备份、替换并写入受管清单；
3. 发生文件错误时恢复备份与旧清单；
4. `POST /api/deploy/push` 只接受清单内文件，保存排队快照并创建后台任务；
5. `GET /api/jobs/{id}` 查询排队、执行、成功或失败状态。

发布页的仓库维护接口与内容同步彼此独立：`/api/deploy/repository/status` 只读状态，`/fetch` 刷新远程引用，`/update` 只允许干净工作区 fast-forward。它们不暂存文件、不创建提交，也不自动处理分叉历史。GitHub 推送由受管清单限定文件范围，Vercel 再通过仓库集成开始构建。

音乐配置使用 `/api/settings/music` 单独读写统一的 `musicTracks`，并生成 `musicIds` 兼容旧配置，避免音乐页保存时覆盖其他站点配置。网易云歌曲通过 `/api/music/query/{id}` 校验数字 ID；酷狗歌曲通过 `/api/music/search/kugou` 搜索并保存 32 位 hash。歌词状态接口自动执行 `SearchLyricAsync -> candidates -> GetLyricAsync(fmt=krc) -> DecodeLyrics -> KrcParser`，不要求上传歌词文件；在线 KRC 失败时公开站回退网易云 YRC/LRC。

目标仓库出现任何未提交改动时，计划会锁定。同步只删除上一份 `.yunyue-managed.json` 记录的过期文件；路径穿越、符号链接逃逸和未知目录均被拒绝。

## 安全边界

- `.env*`、`workspace/`、部署配置和本地端口配置均被 Git 忽略；
- FastAPI CORS 只允许本机 `localhost` 或 `127.0.0.1` 端口；
- Git 命令不使用 shell 字符串，不执行 `reset`、`clean` 或 `push --force`；
- Git 路径通过 NUL 分隔读取，兼容中文文件名和空格；
- 外部接口均限制输入、超时、缓存或调用频率。

## 性能策略

- 首页只加载静态 HTML、CSS 和主视觉；
- 搜索、音乐、AI 与 Bangumi 以 Islands 延迟激活；
- 音乐评论按页面需要加载；
- 主视觉使用 WebP，固定宽高避免布局偏移；
- 减少动画模式下关闭弹幕和非必要过渡。
