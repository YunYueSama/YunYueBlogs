# 云月博客管理端

本目录包含 Next.js 控制台、FastAPI 本机服务与 Windows 桌面启动器。

完整图文说明、安装、跨设备同步和发布流程见[仓库 README](../README.md)。

```powershell
npm.cmd ci
python -m pip install -r requirements.txt
.\Start.bat
```

运行时工作区和账号配置保存在本机，不进入公开仓库；公开内容通过连接的博客仓库在设备间同步。


## 写作、媒体与发布状态

- 编辑器每次停止输入 4 秒后保存草稿。保存期间继续输入会保留未保存状态并继续保存；首次保存新稿不会回读覆盖正在编辑的正文。侧栏、快捷导航和支持 Navigation API 的浏览器后退共用离开提醒，刷新或关闭窗口也会提醒未保存内容。
- 媒体库和选图弹窗每页显示 24 项，支持搜索、翻页和图片懒加载；搜索切换时旧请求会取消。弹窗支持 Tab 焦点约束、Esc 关闭和焦点恢复。
- 发布页面持续显示服务端的提交/推送进度，刷新后可恢复查看最近任务。轮询暂时中断不代表任务失败，不应重复推送。GitHub 已推送与 Vercel 已上线分别展示；当前控制台不把 Git 推送成功当作部署成功，最终部署状态请从配置的 Vercel 项目地址查看。

## 内容快照与服务器更新

普通页面立即读取最近同步的本地内容快照。后台最多每分钟检查一次远程版本，只更新提示，不合并或替换本地正文；网络不可用时仍能浏览快照。页面显示最近同步时间，发现新版本后可点击“更新服务器内容”，此操作先处理未保存的编辑再进行同步。

保存公开设置、应用操作队列、同步仓库和发布仍强制核对远程版本。其他设备已经更新时，旧版本写入会被拒绝，需先更新内容后重新编辑。后台检测到的新版本不会冒充本地快照版本，也不会放宽保存与发布的冲突校验。私密草稿和本地操作队列自动保存仍留在本机。
