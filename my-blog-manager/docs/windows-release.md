本次更新改进了日常管理和多设备协作：

- 快捷导航支持方向键选择、回车打开和中文输入法；弹窗关闭后恢复焦点。
- 媒体上传、登记与移除互斥，避免重复操作和并发覆盖；复制失败时给出明确提示。
- 发布预览与目标仓库的提交、分支绑定，仓库变化后要求重新预览；任务期间锁定相关配置。
- 跨设备修改 Bangumi 用户名时核验内容版本；仅修改图床或密钥仍可离线保存。
- 修复 Windows 并发保存临时文件冲突和媒体记录丢失问题。

Windows 10/11 x64 安装包，内置 Python、Node.js、Git 和 GitHub CLI，无需手动安装开发环境。SHA256SUMS.txt 提供安装文件校验值。

- 首次启动可连接有推送权限的已有 YunYueBlog 仓库，继续管理原博客；现有 Vercel 项目和网址保持不变。
- 也可创建自己名下的私有博客仓库，以中性的站点信息和空白文章、图库、歌单开始。首次上线需在 Vercel 导入新仓库，随后在“外观”填写自己的正式网址并保存发布。
- 通过 GitHub 官方设备授权登录，不需要在管理端填写密码或 Token。
- 个人工作区位于 `%LOCALAPPDATA%\YunYueManager\workspace`，安装包不包含作者的工作区、草稿、密钥或登录文件。
- 换设备后重新授权 GitHub、图床与音乐账号；旧设备未发布的草稿需单独备份迁移。
- 卸载保留个人工作区，更新程序不会清空内容。发布前先同步其他设备的最新修改。

安装时会准备 Microsoft WebView2，首次授权和连接仓库需要网络。安装包目前没有代码签名，Windows 可能提示发布者未知；请核对这里的官方发布地址与 SHA256SUMS.txt。

若新仓库已创建但后续连接失败，不要重复创建同名仓库；可改用“连接已有博客”，填写刚创建的仓库地址。GitHub 推送完成与 Vercel 正式上线分别确认。
